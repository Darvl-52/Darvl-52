## Обо мне

Fullstack-разработчик. Сейчас делаю внутреннее PWA-приложение для сотрудников компании: фронт на Next.js, бэк на NestJS. Задачи беру целиком: обсуждаю требования, пишу интерфейс и API, довожу до релиза.

## Чем занимаюсь

Пишу веб-приложения целиком, от интерфейса до API и базы. Люблю пробовать новые технологии и разбираться, как они устроены. Сейчас много изучаю разработку с ИИ: пишу правила и инструкции для агентов, подключаю инструменты через MCP, веду фичи по спекам в OpenSpec. Ещё копаюсь в производительности фронтенда, от размера бандла до лишних ререндеров и офлайн-режима.
